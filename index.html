ROUAA Institutional Intelligence — Interface Prototype V1
Official-source intelligence for institutional decision environments. Every displayed object is traceable through the evidence chain: intelligence → facts → documents → official source.
This interface is a read-only presentation of a frozen repository production snapshot (wave LSE-V4, snapshot 2026-09-19, Core commit c78b96af53). It is not a live production feed. Intelligence objects, facts, documents, sources, dates and provenance are displayed verbatim as committed by ROUAA Core — nothing is invented, interpolated or embellished by the interface. Where Core has not yet attached a capability (e.g. executive interpretation, undated objects), the interface states so explicitly rather than filling the gap. External links point to canonical URLs recorded at acquisition time.
